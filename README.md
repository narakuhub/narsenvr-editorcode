## OVERVIEW

**Nars Endeavor Ecode** is a lightweight Lua code editor integrated into **Nars's Endeavor**.

It provides a structured development environment with a workspace explorer, multi-tab editor, syntax highlighting, autocomplete, file management, script execution, and an integrated console.

---

## FEATURES

- **Code Editor** — Write and edit Lua scripts in a dedicated editor workspace with syntax highlighting.

- **Explorer** — Browse Lua files from the existing `delta/Autoexecute`, `delta/Script`, and `delta/Workspace` directories.

- **Multi-Tab Editor** — Work with multiple scripts simultaneously while preserving each tab's content and file information.

- **Autocomplete** — Provides Luau keywords, API/member suggestions, service-aware suggestions, and user-defined symbols.

- **Syntax Highlighting** — Built-in syntax highlighting for a cleaner and more readable coding experience.

- **Script Execution** — Execute the currently active Lua script directly from the editor.

- **File Management** — Create, open, save, clear, copy, and delete Lua files through the editor interface.

- **Console** — Integrated output console for viewing execution logs, errors, and other runtime information.

- **Custom Scrolling** — Dedicated vertical and horizontal scrolling for navigating larger scripts.

- **Window Controls** — Floating editor window with drag, resize, minimize, and open functionality.
